# Lamborghini Revuelto AR model

Source: https://www.lamborghini.com/sites/it-en/files/DAM/lamborghini/facelift_2019/model_detail/augmented-reality/revuelto/ar/Revuelto.glb

Linked by the official Revuelto product page's augmented-reality data:
https://www.lamborghini.com/en-en/models/revuelto-models/revuelto

Downloaded 2026-10-03 for this local concept demonstration. Copyright and trademarks remain with their respective owners; this is not an open-source asset license or an official Lamborghini application.

Original: 33,842,852 bytes; 790 glTF meshes / 853 loaded mesh primitives. Embedded textures resized to maximum 1024 pixels and recompressed, preserving geometry. Optimized file approximately 20.8 MB. Runtime groups into 371 spatial/material parts for the exploded view; all assembled cars merge by material to reduce draw calls. Separation directions are an artistic visualization, not an engineering disassembly guide.

Three.js is MIT licensed; see ../THREE-LICENSE.txt. The compiled local JavaScript is built from src/vehicle-3d.js using the pinned dependencies in package-lock.json.
